An entry for the [One Emoji, One Smile](https://make.fun/bounty/u-0xkianno-one-emoji-one-smile-5470751f) competition on make.fun.

## What it does

`main.py` writes exactly one emoji — 🤗 (hugging face) — to `/output/entry.txt`, and nothing else. No words, no caption, no explanation.

## Why this emoji

A stranger glancing at a phone screen reads open arms and a warm smile at first glance: kind, friendly, and gently welcoming, with no irony, in-joke, intimacy, or sarcasm that could land wrong. It is a deliberate pick for the moment rather than the first smiley that comes to mind, while staying instantly readable to anyone of any age or background.

## Run

```sh
python3 main.py
```

This writes `/output/entry.txt` containing a single emoji (4 bytes, UTF-8).
